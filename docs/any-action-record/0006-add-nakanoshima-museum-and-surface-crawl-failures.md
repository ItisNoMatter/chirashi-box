# 0006: 大阪中之島美術館を巡回先に加え、巡回の失敗に気づけるようにした

- Date: 2026-10-13
- Related AnyDR: AnyDR 0025, AnyDR 0030

## Objective
大阪中之島美術館を巡回先に加え、本番で展示が出るようにする。

## Action
- 規約を確認した。robots.txt は巡回を許していた。サイトポリシーには「営利を目的としない限りリンクは自由」とあり、画像の直接リンクやスクレイピングを禁じる記述はなかった。著作権の一般的な条項だけだったので、AnyDR 0025 に沿って、これまでの7館と同じ扱いにした。
- ローカルで巡回を試した。展示7件が入り、会期を公式サイトと照らし合わせた（費用は約 $0.17）。
- 本番 DB に会場・巡回対象・サイトポリシーの3行を入れ、手動で巡回した。この館だけが、Anthropic API のクレジット残高不足（400）で失敗した。
- ユーザーが $20 のクレジットを購入した。再度巡回し、7件が本番に入った。
- 1館でも失敗したらジョブを失敗にするよう直した（AnyDR 0030、コミット f893bde）。

## Result
- 本番の巡回先は8館になった。大阪中之島美術館の展示7件が表示されている。
- 実績の費用：初めて全館を巡回したとき約 $0.65、1館を追加したとき約 $0.17、変化の少ない夜の巡回は約 $0.01。ふだんの月は $0.5〜1 程度と見積もった。$20 は、使い切るより先にクレジットの有効期限（購入から1年のはず）が来る見込み。

## Reflections
- クレジット切れで1館が失敗しても、ほかの館が API を呼ばずに済んでいたため、GitHub Actions には「成功」と表示された。「全館が失敗したときだけ失敗にする」作りは、館どうしで共通の原因（API キーやクレジット）による失敗を、たまたま目立たなくしてしまう。
- 一覧ページのハッシュを最後まで処理できたときにだけ保存する作りにしていたので、失敗した館は次の巡回で自動的にやり直される。おかげで、失敗に気づいてからの復旧は「クレジットを買って、もう一度走らせる」だけで済んだ。
- ローカルでは通った数分後に CI で失敗したので、ローカルと CI で別のキーが使われている可能性も疑った。どちらが原因だったかまでは確かめていないが、クレジットを買ったら CI でも通った。クレジットの残高も、外部依存のひとつとして監視する対象に入れるべきだった。
