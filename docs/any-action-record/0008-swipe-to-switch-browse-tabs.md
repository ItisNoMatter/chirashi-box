# 0008: 眺めるページのタブを横スワイプで切り替えられるようにした

- Date: 2026-10-13
- Related AnyDR: AnyDR 0032

## Objective
横スワイプで「開催中」「もうすぐ」を切り替えたい、というユーザーの要望に応える。前提として、PWA でも実現できるかを確かめる。

## Action
- PWA でもブラウザのタッチイベントで作れることを確かめた。そのうえで、気をつける点を3つ挙げた。
  - チップの行も横にスクロールする
  - 縦のスクロールと混ざる
  - iPhone では画面の端からのスワイプが「戻る」と重なる
- 3つの案を比べた（指を離したときに判定する、scroll-snap で指に追従させる、ライブラリを使う）。両方のタブのデータを最初から読み込まずに済み、0031 で速くした表示を保てる、指を離したときに判定する案を選んだ。
- スワイプかどうかの判定を純粋な関数 `swipeOf` にまとめ、テストを先に書いてから実装した（6件）。
- `BrowseFilters` に組み込んだ。スワイプはグリッドの上だけで受け取り、切り替えはタブを押したときと同じ処理を通す。
- 手元で本番と同じ形にビルドし、ブラウザで指の動きを再現して確かめた。その後、本番にデプロイした（コミット 733cc8b）。

## Result
- 手元の確認では、次の5つの動きがすべて期待どおりだった。
  - 左へスワイプすると、もうすぐに切り替わる
  - 端のタブでは止まる
  - 斜めの動きでは切り替わらない
  - 画面の端からのスワイプは無視する
  - 右へスワイプすると、開催中に戻る
- ユーザーが iPhone の実機で試し、「いい感じ」とのことだった。判定のしきい値（60px、1.5倍、24px）は変えずに済んだ。
- テストは83件、すべて通った。

## Reflections
- 「PWA だと難しいか」という問いへの答えは、技術的にできるかよりも、周りの操作（チップの横スクロール、縦のスクロール、OS の「戻る」）とぶつからないかで決まった。
- いちばんネイティブアプリらしい案（指に追従させる案）は、直前に直した表示の速さと引き換えになる。シンプルな案から始めて実機で触ってもらう順番にしたので、作り込まずに済んだ。
- ブラウザで確かめている途中、確認用のタブが裏に回っていると、ブラウザが描画を止めるため、データが差し替わらず仮の表示のままに見えた。アプリの不具合と取り違えかけたので、ブラウザで自動確認するときはタブを前面に出してから測る。
