# 0025: サイトごとのリンク・画像の制限に合わせて表示を切り替え、並行して許可を申し込む

- Date: 2026-10-11
- Status: Accepted
- Category: architecture
- Deciders: the user, Claude Code

## Context
ういぴさんが指定した最初の巡回対象7館（国立西洋美術館、国立新美術館、三菱一号館美術館、東京都美術館、森美術館、東京都現代美術館、アーティゾン美術館）について、robots.txtと利用規約を確認した（0016）。7館とも robots.txt は巡回を許可しており、自動での収集を明示的に禁じる規約もなかった。著作物の複製を禁じる条項は、事実の項目だけを保存し画像を複製しない設計（0007、0016）で守れている。一方で、次の3館にはアプリの表示と衝突する制限があった。
- 国立西洋美術館：「画像やＰＤＦファイルへの直接リンクはご遠慮ください」
- 三菱一号館美術館：「当社に無断で当ウェブサイトへのリンクを張ることはできません」
- 森美術館：リンクは事前の申し込み制

## Decision
- 7館すべてを巡回対象にする。
- ドメインごとに「リンクを出してよいか」「画像を直接表示してよいか」を持ち、制限のあるサイトでは、公式ページへのリンクや館の画像の表示を外す（画像は自動生成のチラシにする）。巡回でもURL登録でも、同じドメインのページには同じ制限がかかるよう、巡回対象ではなくドメイン単位で持つ。
- 表示するときに制限を当てはめ、保存するデータは変えない。許可が取れたら、制限の印を外すだけで本来の表示に戻せる。
- 並行して、三菱一号館美術館と森美術館にリンクの許可を申し込む（申し込みの文面はClaude Codeが下書きし、送るのはユーザー）。

## Alternatives
- 制限のない4館で巡回を始め、3館は許可を取ってから加える: 規約は確実に守れるが、ういぴさんが指定した館のうち3館が、いつまでか分からないまま一覧に出ない。
- 3館も巡回して制限に触れる部分だけを外すが、許可は取りにいかない: 規約には沿うが、リンクが出ない不便さが残り続ける。

## Consequences
- 三菱一号館美術館と森美術館の展示は、許可が取れるまで、詳細ページから公式ページに飛べない。
- 国立西洋美術館の展示は、画像を表示せず自動生成のチラシになる（もともと og:image がない）。
- サイトごとの制限のテーブルと、表示の分岐が増える。
